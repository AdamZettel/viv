# One case per line: name | expression | reduce
# The expression is evaluated once per iteration of a loop that runs N times;
# `reduce` turns its value into a number (sum for arrays, len for strings).
# Setup available to every case: a (64 numbers), m (8 x 8), spd (8 x 8,
# symmetric positive definite), b8 (8 numbers), mp (a map of
# 16 numbers), g(v) a def returning v * 2.0, R a record with an array field,
# mkmap(k) a def that makes a map, stores one key and returns its length,
# mksmap(k) the same with a map of strings (the leak of
# study/compare/strings/parse_numbers.viv).
elementwise_add   | a + a                  | sum
elementwise_sin   | sin(a)                 | sum
linspace          | linspace(0.0, 1.0, 64) | sum
zeros             | zeros(64)              | sum
array_literal     | [1.0, 2.0, 3.0, k]     | sum
copy              | copy(a)                | sum
concat            | concat(a, a)           | sum
transpose         | transpose(m)           | sum
hcat              | hcat(m, m)             | sum
matmul            | m @ m                  | sum
slice             | a[2:10]                | sum
vcat              | vcat(m, m)             | sum
shape             | shape(m)               | sum
roll              | roll(a, 1)             | sum
keys              | keys(mp)               | sum
values            | values(mp)             | sum
def_returning_arr | g(a)                   | sum
record_field      | R { xs: a + a }.xs     | sum
str               | str(k)                 | len
fstring           | f"k = {k}"             | len
upper             | upper("abc")           | len
string_concat     | "a" + str(k)           | len
map_per_iteration | mkmap(k)               | id
map_of_strings    | mksmap(k)              | id
