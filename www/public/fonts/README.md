# Fonts served by viv-lang.org

Both are under the SIL Open Font License 1.1 (the OFL-*.txt files here), taken from
github.com/google/fonts (ofl/outfit, ofl/jetbrainsmono) on 2026-10-12 and subset to
Latin, Greek, punctuation, arrows, math operators and box drawing with fontTools'
pyftsubset (woff2). Neither copyright line declares a Reserved Font Name, so the
subsets keep their names.

- Outfit-wght.woff2: Outfit, variable weight 100-900. The UI, headings and text.
- JetBrainsMono-wght.woff2: JetBrains Mono, variable weight 100-800. Code.
