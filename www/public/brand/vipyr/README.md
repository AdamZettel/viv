# vipyr logo

- `vipyr-logo-light.svg` / `-dark.svg`: the lockup (mark + wordmark) for light and dark backgrounds.
- `vipyr-mark-light.svg` / `-dark.svg`: the snake V alone.
- `vipyr-icon.svg` (dark tile) / `vipyr-icon-light.svg` (green tile): avatar, PyPI, app icon.
- PNGs: lockups at 3x, icon at 512 and 180 (Apple touch), favicons at 32 and 16.

Wordmark: Outfit SemiBold (weight 560), converted to outlines, so no font is needed to display it.
Outfit is under the SIL Open Font License 1.1 (FONT-LICENSE-Outfit-OFL.txt); using its outlines in a logo is allowed.

Colors: viper green #1f8a5b → #2fb67a (light), #3fd08e (dark); ink #0f2a22; light text #e8efe9;
eye #f2b632 / #f2c14e; tongue #d43f3f / #ff6b6b. Python's own blue and yellow are deliberately not used.
